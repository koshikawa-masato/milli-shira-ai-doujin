### 判定ボットの検討
- Ollama Cloud は推論専用（学習・画像生成は不可）→ 学習時間の短縮には無関係。VLM 判定の候補として Claude API / Gemini / OpenRouter(Qwen3-VL) / ローカル を比較
- Mac（M5 32GB）で gemma4 を測定: ポケット判定 76%、黒目なし・耳ピンクの検出 0/4 → 不採用、削除
- Qwen3-VL 32B: 32K コンテキストだと 29GB で CPU に溢れて 0.3 tok/s、4K でも判定中にメモリ逼迫。結果はポケット一致 15/25（NG 検出 0/8）、281 秒/枚 → **不採用、削除**。ローカル VLM での細部判定は断念、判定ボットは Claude API で組む方針
- Claude API は環境の鍵が無効で未測定
