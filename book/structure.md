# 構成案（B5 / 20ページ）

判断：最初の1冊は「漫画長編」ではなく、**文章 + 挿絵 + 作例** で出す。
タイトルぜんたいの内容になるし、キャラ一貫性の難易度を下げられる。

## ページ割り

| ページ | 内容 |
|---|---|
| 01 | 表紙 |
| 02 | 奥付・注意書き |
| 03 | 目次 |
| 04-05 | 0. なぜこの本を作るのか |
| 06-07 | 1. コミケとは何か（ミリしら解説） |
| 08-09 | 2. 申込までの実際 |
| 10-13 | 3. AIで全部作るための設計 |
| 14-15 | 4. 失敗と学び |
| 16-17 | 5. 作例（生成画像と使った指示） |
| 18-19 | 6. 再現手順とGitHub案内 |
| 20 | あとがき |

## 各章の役割

- **0** 動機。ミリしらでも起こせることを書く
- **1** 読者を置いていくための用語解説
- **2** 手続きだけ書く。通りの手帳にしない
- **3** この本の核。工程、工具、記録の残し方
- **4** うまくいかない部分を隠さない
- **5** 画で見せる
- **6** QRでこのリポジトリへ案内する

## 入れないもの

- 長いストーリー漫画
- 二次創作
- 工具の使い方を詳しく書くチュートリアル
- 本編に全プロンプトを載せること
