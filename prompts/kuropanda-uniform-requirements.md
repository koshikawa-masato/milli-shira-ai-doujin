## 工程（要件確定後の実行計画、2026-08-23）

1. **口を閉じた微笑 Oracle**: **制服バストアップの正（`edit/…225035-379`、顔 = A の画素）**の口元だけを直す → **承認済み `oracle/bust_smile_hand_v5.png`（2026-08-23、★）**。以後の顔の画素はこれ。口は「\\__/ の角に小さな R、端は緩やか」（Catmull-Rom、中央 ±16px 平ら、端 ±29px で 3px 上がる、線は中央 2.6px・端 1.1px）。※ 08-23 にパーカーの A で 6 回やったのは対象の取り違え。AI のマスク編集は口を閉じられなかったので手描き。B の顔で作った版は不要（等身 Oracle の B は顔の供給源ではない）
2. **高一 正面**: 等身 Oracle（`oracle/…418_1`）を土台に、白背景・直立・手を斜め下へ（マスクで背景と腕だけ）→ 写真を参照に制服を部位ごとに 1MP 切り出し編集 → 承認済みの顔を画素合成
3. **高一 横・後ろ・斜め**: 正面と写真を参照に体型を描き、同じ部位方式で制服を合わせる。横の襟は着用写真を参照
4. **高 3**: 体型 Oracle（横・後ろ）と 158 cm・胸の差分で同じ 4 面
5. **イベント版**: 各面に青い蝶結びリボンをマスク編集で追加
6. 各工程で**部位ごとの合否表**（要件の「足りないもの」表の項目）を付けて天の声に出す。NG の部位だけ再編集

## 運用ルール（2026-08-23 天の声の指摘から）
- GPU ジョブを投げる前に、**実際に送る文章（英文と日本語訳）と対象画像・参照画像をこの場に出す**。天の声の言葉を Claude が言い換えた箇所が分かるようにする
- Oracle の取り違えをしない: **顔 = A（制服版 = 制服バストアップの正）、高一の等身 = B、高 3 の体型 = 横・後ろ**。昨日の決定（顔は A に画素で合わせる）は生きている
- **役割分担の原則（天の声 2026-08-23）**: 想像で生み出す必要のあること（別角度、新しいポーズ、無いものを描く）だけ Krea2 / 編集モデルに任せる。**決定論的な画像変換（切り抜き・鏡像・合成・線の加減・マスク固定）はスクリプト**で行い、同じ入力から同じ結果を再生成できるようにする（`tools/uniform-pipeline/`）。**Oracle は我々が組み立てる**。Oracle が無いと Krea2 は想像を働かせられない。今回の「肩の付け根の馴染ませ」も AI でなく鏡像コピーで済ませるべきだった
