### Oracle を基準にするために足りないもの（Claude の見立て、2026-08-23）

| 項目 | いまある | 足りない |
|---|---|---|
| 顔（正面） | A（パーカー・バストアップ、v2 step800 seed0） | なし。ただし「画素一致」か「似ていれば可」かの判定基準 |
| 顔（横・後ろ） | 横＝要件 3、後ろ＝要件 4（どちらも高 3 の体型。服は対象外） | **真横の顔**と**後ろ頭（髪の形・襟足・つむじ）**の承認済み絵。これが無いので横・後ろは毎回推測になっていた |
| 等身（高一） | 候補 B / C（未確定） | **どれかの確定**。手を振るポーズは肩と腕が隠れるので、**腕を下ろした直立**の全身があると三面図の基準になる |
| 等身（高 3） | 横向き（要件 3） | **正面**の全身（横だけだと肩幅・胸の出方が決まらない）。高一との差分の言葉（身長・胸・髪の長さは同じか） |
| 制服（写真） | 正面・背面・襟・セット・複数の 5 枚（ハンガー吊り） | **横からの写真**（襟の前の傾き・後ろの垂れ。横図が崩れた直接の原因）、**着用時の写真**（裾がスカートの上に出る様子、襟の座り）、**ソックス・ローファーの写真**（今は言葉だけ） |
| 制服（判定表） | 設定シートの文章 | **部位ごとの合否チェック表**（襟の線 2 本＝紺外・緑内／刺繍の位置と向き／ポケットのタグ／ボタン数／裾の箱型と中央の切れ込み／背中の襟と縫い目／プリーツの数と丈／ソックス丈／ローファーの形） |
| 表情 | Oracle は口を開けた笑顔 | 三面図は**無表情 or 微笑**にするか。Oracle の表情のまま三面図にすると顔合わせが難しい |
| 成果物の規定 | なし | 背景（白か教室か）、ポーズ（直立 A ポーズか）、出力サイズ、枚数（正面・横・後ろ＋必要なら斜め） |
