# ADR-0002 仕様・ジャンル・公開方針

- 日付: 2026-08-18
- 状態: 採用

## 決めたこと

- 仕様: B5 / 20ページ
- 部数: 最初は100部目安
- ジャンル候補: 114 歴史・創作(文芸・小説)
  - 代替: 600 評論・情報
- 制作ログの正本: GitHub Public
- 本の中ではQRと短い案内のみ載せる

## 理由

- 20ページは初回で組めやすい
- 文章中心なら創作文芸で通る
- 記事寄りが強ければ600に変更する
- PublicにするとログインなしでQRから読める

## 返さないもの

- 个人情報
- APIキー
- 不採用画像の全量
- 他者の著作物
